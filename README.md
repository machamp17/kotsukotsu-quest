# こつこつクリニック クエスト

訪問診療医になって、町の専門職とつながりながら患者さんを支える、スマートフォン向けのレトロRPG。
ホームドクターこつこつクリニック。生きることを嬉しく。

- 公開URL：https://quest.kotsukotsu-clinic.com/
- このリポジトリがゲームの**正本（いちばん新しい完成版）**です。Claude などの作業環境が使えなくなっても、このリポジトリと公開サイトはそのまま残り、動き続けます。

## ゲーム本体（`docs/` フォルダ）

| ファイル | 中身 |
|---|---|
| `docs/index.html` | ゲーム本体。この1ファイルにすべて入っている（絵・音楽・効果音もコードで描画・合成。画像素材なし） |
| `docs/ogp.png` | LINE・SNSでURLを送ったときに出る画像 |
| `docs/apple-touch-icon.png` | iPhoneのホーム画面アイコン（180px） |

| `docs/favicon.png` | ブラウザのタブのアイコン |

| `docs/manifest.webmanifest` | ホーム画面に追加したときの名前・全画面表示などの設定 |
| `docs/CNAME` | 独自ドメイン（quest.kotsukotsu-clinic.com）の設定 |

パソコンで遊ぶときは `docs/index.html` をダブルクリックするだけで動きます（インターネットがなくても遊べます。文字の形だけ標準のフォントになります）。
セーブデータはブラウザの中（localStorage）に保存されます。iPhoneでは Safari とホーム画面アプリでセーブデータが別々になります。

## 公開のしくみ

- **GitHub Pages**：このリポジトリの `main` ブランチの `docs/` フォルダをそのまま公開しています（Settings → Pages）。
  `docs/` の中身を更新して `main` に入れると、1〜2分で公開サイトに反映されます。
- **独自ドメイン**：kotsukotsu-clinic.com はエックスサーバーで管理。DNSに次の1行を追加済みです。
  | ホスト名 | 種別 | 内容 |
  |---|---|---|
  | quest.kotsukotsu-clinic.com | CNAME | machamp17.github.io |
- **HTTPS**：Settings → Pages の「Enforce HTTPS」をオン。証明書は GitHub が自動で更新します。
  もし「証明書がまだ発行されていない」と出たら、同じ画面でカスタムドメインを「削除」→ 入れ直して「保存」すると発行がやり直されます。
- ドメインとエックスサーバーの契約が切れるとアドレスが使えなくなるので、更新（自動更新）を続けてください。

## バックアップのとり方

- GitHub のこのページで「Code」→「Download ZIP」を押すと、すべてを1つのZIPで保存できます。大きな変更の前後に1つ保存しておくと安心です。
- ZIPの中の `docs/index.html` を開けば、そのまま遊べます。

## 手直しのしかた

ゲームの手直しは `docs/index.html` を直接編集します（`src/` は古い版なので使いません。下の「古いソースについて」参照）。

セリフなど日本語の多くは `\u30B3` のような形式で書かれているため、普通に検索しても見つからないことがあります。次の道具を使ってください（Python 3 が必要）。

```
python tools/find-text.py "じっくり聴いた"                # 文章がどこにあるか探す
python tools/replace-text.py "今の文章" "新しい文章"       # 1か所だけ書き換える（複数あるときは何もしない）
```

書き換えたら、ブラウザで `docs/index.html` を開いて確認し、`main` に入れれば公開されます。

## 動作確認（自動通しプレイ）

最初からエンディングまで自動で遊んで、止まる場所やエラーがないかを確認できます（Node.js が必要）。

```
npm install playwright
npx playwright install chromium
node tools/playthrough-test.js 390 844 check noshots
```

約4〜5分で終わり、最後に `FINAL STEP: free` と出ればエンディングまで到達しています。
結果は `test-output/check/` に保存されます（`PAGEERROR` や `CONSOLE` の行が出たら要確認。`OFFSCREEN` はエンディングロールの文字が画面外を流れているだけなので問題ありません）。
`noshots` を外すと、場面ごとの画面写真も保存されます。

## ゲームの中身（2026年11月時点）

- 章：プロローグ → 第1章（レントゲン）→ 第2章（心電図）→ 第3章（眼科検査・薬）→ 第4章（エコー）→ 最終章 → エンディングロール
- 敵：ふあんのモヤ、みおとしコウモリ、つたわらん、最終ボス「孤独の魔王コリツ」（孤立の壁）。病気や患者さんを敵にしない。
- バトル：コマンドは「向き合う／にげる」。動くメーターを止める4段階（例：一方的に話す／相づちだけ／じっくり聴く／寄り添う）で効き目が変わる。仲間が増えるほど一番よいゾーンが広がる。攻撃時は「パコン」と前に出る演出。仲間は戦闘中に1人ずつ駆けつける。
- クリニックのキャラクター10人が町にいて、話しかけられる。エンディングではクリニックの MISSION／VISION／VALUE と「こつこつ」の由来を流す。
- 表記：「生きることを嬉しく。」「ケアマネジャー」で統一。
- 主人公の名前の初期値は「こつ太郎」。「コツコツ」は名前に使えない。
- スマホのダブルタップ・ピンチで画面が拡大しないよう対策済み。

### 素材

絵文字・画像ファイルは使っていない。キャラクター（16x24、4方向 x 静止+歩行2コマ）、顔グラフィック、タイル、建物、機器アイコン、敵、ボスはすべて `src/engine/` のコードで描くオリジナルのドット絵。音は Web Audio で合成したオリジナル曲・効果音（初期状態は消音）。

### 操作

- 十字キー：タップで1マス、長押し（0.3秒以上）で歩き続ける。キーボードは矢印・WASD
- Aボタン：話す・調べる・次へ（Enter・Space・Z）
- メニュー：あらすじ、次の目的、仲間、持ち物、音、タイトルへ
